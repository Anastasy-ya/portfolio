## 🧬 Клеточный Автомат «Жизнь» Конвея

**«Игра Жизнь» (Conway’s Game of Life)** — это классический **клеточный автомат**, разработанный британским математиком Джоном Хортоном Конвеем в 1970 году. Модель демонстрирует, как **сложное поведение** может возникнуть из **нескольких простых правил** взаимодействия элементов.

Фундамент игры — бесконечное двумерное поле, состоящее из клеток, каждая из которых может находиться в одном из двух состояний: **живое** (активное) или **мёртвое** (неактивное).

Эволюция системы происходит по дискретным шагам (поколениям) и определяется состоянием восьми ближайших соседей клетки:

| Правило | Условие | Результат |
| :--- | :--- | :--- |
| **Выживание** | Живая клетка выживает, если у нее 2 или 3 живых соседа. | **Состояние сохраняется** |
| **Рождение** | Мёртвая клетка оживает, если у нее ровно 3 живых соседа. | **Клетка становится живой** |
| **Смерть** | Все остальные случаи (одиночество или перенаселение). | **Клетка становится мёртвой** |

### 🌐 Феномены и Сообщество

С момента своего создания «Игра Жизнь» вдохновила обширное сообщество энтузиастов и исследователей. Они открыли и каталогизировали тысячи уникальных стартовых конфигураций, демонстрирующих четыре основных типа поведения:

1.  **Стабильные фигуры (Still Lifes):** Не меняют своего состояния в следующих поколениях (например, *Блоки, Ульи*).
2.  **Осцилляторы (Oscillators):** Периодически возвращаются в исходное состояние (например, *Семафоры, Жабы*).
3.  **Движущиеся объекты (Spaceships):** Фигуры, которые смещаются по полю с определенной скоростью (например, *Планеры, Космические корабли*).
4.  **Сложные конструкции:** Системы, которые способны к самовоспроизведению, уничтожению или генерации других объектов:
    * **«Ружья» (Guns):** Фигуры, бесконечно производящие движущиеся объекты (например, *Ружьё Глайдера*).
    * **«Пожиратели» (Eaters):** Фигуры, способные поглощать другие движущиеся объекты.

Эти конструкции служат основой для создания сложных вычислительных машин внутри самой «Жизни», демонстрируя её способность быть **Тьюринг-полной**.
